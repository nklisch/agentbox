# Pattern: Pure String Generator Function

`Generate*` functions take a struct, produce a string, and have no side effects.

## Rationale

Config/script files generated by agentbox (Dockerfile, Corefile, Zellij KDL layout) need to be deterministic and testable. Pure functions make this easy: same input → same bytes, trivially unit-testable, caller decides where to write the output.

## Examples

### Example 1: Dockerfile generation
**File**: `internal/kits/dockerfile.go:15`
```go
// GenerateDockerfile produces the multi-stage Dockerfile for a resolved kit set.
// Deterministic: same Resolved + version → same bytes. Caller writes to disk.
func GenerateDockerfile(res Resolved, agentboxVersion string) string {
    var b strings.Builder
    fmt.Fprintf(&b, "# Generated by agentbox %s\n", agentboxVersion)
    // ... template logic
    return b.String()
}
```

### Example 2: Corefile generation
**File**: `internal/network/corefile.go:21`
```go
// GenerateCorefile produces the CoreDNS config for the given network spec.
// Dispatches to safeCorefile or allowlistCorefile based on Mode.
func GenerateCorefile(spec Spec) string {
    switch spec.Mode {
    case ModeSafe:
        return safeCorefile(spec.Cfg.Network.Safe)
    case ModeAllowlist:
        return allowlistCorefile(spec.Cfg.Network.Allowlist)
    default:
        return ""
    }
}
```

### Example 3: Zellij KDL layout generation
**File**: `internal/zellij/kdl.go:31`
```go
// GenerateKDL produces the KDL layout file for the given layout spec.
// Dispatches to built-in generators or returns the custom KDL body.
func GenerateKDL(l Layout) string {
    if l.CustomKDL != "" {
        return l.CustomKDL
    }
    switch l.LayoutName {
    case "focus":   return focusLayout(l)
    case "reviewer": return reviewerLayout(l)
    case "auditor":  return auditorLayout(l)
    }
    return focusLayout(l)
}
```

### Example 4: Caller pattern (write to disk after generation)
**File**: `internal/lifecycle/lifecycle.go:305`
```go
body := zellij.GenerateKDL(layout)
// caller writes body to disk:
return os.WriteFile(filepath.Join(dir, "layout.kdl"), []byte(body), 0o600)
```

## When to Use
- Generating text/config files from structured input (Dockerfiles, config files, layout files)
- Any transformation where the same input must always produce the same output
- When the output needs to be tested for exact content

## When NOT to Use
- Don't inject writers into `Generate*` functions — return the string and let the caller write
- Don't add I/O side effects (logging, file writes) inside a `Generate*` function

## Common Violations
- Taking an `io.Writer` parameter and writing directly instead of returning a string — makes testing harder (requires capturing the writer)
- Non-deterministic output (e.g., map iteration order) — always sort slices before generating
