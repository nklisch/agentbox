# Changelog

All notable changes to agentbox. Versions follow [SemVer](https://semver.org/).
Each release also gets autogenerated notes from goreleaser on the GitHub
Releases page; this file is the curated companion.

## v0.2.4 (2026-05-05)

**Improvements**

- **Git pane shows the branch.** The zellij git-status pane was running `watch git status -s`; `-s` (short format) intentionally hides the branch header. Switched to `-sb`, which adds `## main...origin/main [ahead N, behind M]` (or `## HEAD (no branch)` when detached) above the file list. One-character fix, big legibility win.

## v0.2.3 (2026-05-05)

**Improvements**

- **Zellij tab bar and status bar are now visible inside the box.** The generated layout wraps every tab in a `default_tab_template` that ships zellij's built-in `tab-bar` (top, 1 row) and `status-bar` (bottom, 2 rows) plugins. Users can now see the active mode (pane / tab / session / search / move / resize) and its keybinds at all times — no more guessing how to detach. Total chrome cost: 3 rows.
- **README detach instruction corrected.** Fixed `Ctrl+p d` → `Ctrl+o d` (`Ctrl+o` enters session mode; `d` detaches). The wrong keybind had been documented since v0.1.0.

## v0.2.2 (2026-05-05)

**Fixes**

- **`podman create: exit status 125` when `containers.enable = true`.** Latent bug exposed by v0.2.0's flip of the default. `runspec` was emitting `--security-opt seccomp=/etc/agentbox/seccomp/containers.json` — an in-container path. Podman reads `--security-opt` from the **host** filesystem at create time, before the container's filesystem exists, so the lookup failed and create exited 125. Fix: use the host path (`in.SeccompPath`) populated by lifecycle. The in-container bind mount is preserved for in-box introspection.
- **`podman create: exit status 125` was opaque.** The runtime was discarding podman's stderr (`cmd.Stderr = io.Discard` in `internal/container/podman.go`), so failures surfaced only as exit codes. `Create`, `Start`, and `Stop` now capture stderr and include the trimmed message in the returned error so users see *why* podman failed.

## v0.2.1 (2026-05-05)

**Fixes**

- **Claude Code agent works in fresh boxes.** Two issues stacked: (1) Claude Code refuses `--dangerously-skip-permissions` when running as root ([claude-code#9184](https://github.com/anthropics/claude-code/issues/9184)), and (2) only `~/.claude/` was bind-mounted, not the sibling `~/.claude.json` where Claude Code stores its primary config. v0.2.1 sets `IS_SANDBOX=1` on the box (the community-known bypass for the root refusal) and adds a sibling-file mount for `~/.claude.json`. Lifecycle touches the source file empty if missing so podman doesn't bind-mount a directory in its place. Run `agentbox run --fresh` to pick up the new mounts on existing boxes.

## v0.2.0 (2026-05-05)

**Features**

- **Easy install** — `curl | sh` installer, prebuilt tarballs on GitHub Releases (`linux/amd64`, `linux/arm64`, `darwin/arm64`), and `go install` documentation. The installer verifies sha256, idempotently adds `~/.local/bin` to `PATH` via a sentinel-wrapped shell-rc block, and strips the macOS Gatekeeper quarantine attribute on darwin.
- **Config write commands** — `agentbox config set/unset <key> <value>`, `agentbox config network <mode>`, `agentbox config containers on|off`, and `agentbox config kits add/remove <name>` for scripted, non-interactive config mutation without opening `$EDITOR`. Writes atomically; validates before touching disk.
- **Containers enabled by default** — `containers.enable` now defaults to `true`. The `containers` kit was already in `default_kits`; the runtime privileges now match, so `docker run` inside a fresh box works without extra config.

**Improvements**

- Base kit gains `git-lfs`, `tree`, `make`, `gron`, a `jgrep` wrapper, `gh` (GitHub CLI), and `glab` (GitLab CLI).
- `agentbox doctor` resolves real binary paths for the sudoers suggestion (via `exec.LookPath` + fallback to install prefix) rather than guessing distro-specific paths.

**Fixes**

- Shell completion docs updated to user-level paths — bash uses `~/.local/share/bash-completion/completions/agentbox`, no `sudo` required.

## v0.1.0 (2026-05-05)

Initial release. All eight ROADMAP phases shipped end-to-end:

- CLI: `agentbox run/shell/exec/attach/ls/rm/build/doctor/config/completion`.
- 12 built-in kits: `base`, six single-language kits (`node`, `python`, `go`, `rust`, `systems`, `cloud`), `polyglot`, three agents (`claude`, `codex`, `opencode`), and `containers` (nested rootless podman).
- Container lifecycle with same-path bind mounts, label-based discovery, persistent state.
- Zellij in-box layout with agent main pane + git status ticker + system stats.
- Network policy: `safe` (DNS threat-feed + IP-level egress filter) and `allowlist` modes via per-box CoreDNS sidecar + `agentbox-netfilter`.
- Nested rootless podman without `--privileged` or host docker socket.
- macOS Apple Silicon support via `podman machine`.
- `--runtime docker` fallback adapter.
